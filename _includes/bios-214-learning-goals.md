By the end of this mini-course, students will be able to:

1. Design basic MRI pulse sequences using [Pulseq](https://github.com/JuliaHealth/Pulseq.jl).
2. Simulate MRI experiments using Bloch simulations in [KomaMRI](https://juliahealth.org/KomaMRI.jl/stable/).
3. Reconstruct MRI data using [BartIO](https://github.com/MagneticResonanceImaging/BartIO.jl) and [MRIReco](https://magneticresonanceimaging.github.io/MRIReco.jl/stable/).
4. Analyze the impact of sequence parameters on image contrast and artifacts.
5. Implement and iterate on sequence designs using a rapid prototyping workflow.
6. Evaluate sequence performance through simulation and scanner experiments.
